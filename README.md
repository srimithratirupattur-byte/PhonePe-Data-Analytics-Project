# PhonePe Pulse Data Visualization

Interactive Power BI dashboard on PhonePe Pulse data: transactions and users across Indian states and districts, 2018 to 2022.

## Dashboard pages
- Overview: geo map, KPI cards and filters
- Trends: transactions by type, quarter, year and mobile brand
- Top Performers: top 10 states and districts, YoY growth and CAGR
- Insights: key business findings

## Features
- 10 dropdown filters (state, year, quarter, transaction type, brand, district, metric and more)
- KPIs: total transactions, total amount, average transaction value, registered users, districts

## Tool
Power BI Desktop

## How to open
Download PhonePe_Data_Visualization final dashboard.pbix and open it in Power BI Desktop.
